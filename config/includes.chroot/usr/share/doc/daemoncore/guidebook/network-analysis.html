Network discovery and packet analysis

Start quietly, identify what exists, and save reproducible evidence.

Guidebook homeLab setup
Active scans create traffic and logs. Confirm the target and rate limits before using Nmap or Masscan.

Understand your own interface

ip -brief address
ip route
ss -tulpn

These commands inspect DaemonCore itself. Record the interface and route used to reach the authorized lab before capturing traffic.

Low-impact host and service discovery

nmap -sn 192.0.2.0/24 -oA ~/engagements/lab-01/scans/host-discovery
nmap -sV --version-light -T3 192.0.2.10 -oA ~/engagements/lab-01/scans/services

-oA preserves normal, XML, and grepable output. Start with a conservative timing profile. Avoid scanning every port or using intrusive scripts unless the scope specifically allows it.

Capture and inspect traffic

sudo tcpdump -i any -nn -c 200 -w ~/engagements/lab-01/captures/sample.pcap

Open the capture in Wireshark. Useful display filters include:

FilterQuestion
dnsWhich names were queried?
tcp.flags.syn == 1 && tcp.flags.ack == 0Which new TCP connections were attempted?
ip.addr == 192.0.2.10What traffic involved the scoped host?
http.requestWhich unencrypted HTTP requests are visible?

Report what matters

A useful finding names the asset, observed service, evidence timestamp, security impact, confidence, and remediation. An open port by itself is an observation—not automatically a vulnerability.
