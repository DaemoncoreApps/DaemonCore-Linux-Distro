DaemonCore Linux

Security tooling for defenders, students, and authorized testers.

Permission first. Only assess systems you own or have explicit written authorization to test.

Begin safely

  1. Connect only to an isolated lab or an authorized network.
  2. Update package metadata with sudo apt update.
  3. Create a working directory and keep notes for every engagement.
  4. Use the Applications menu to browse tools by their Debian category.

Install

Launch Install DaemonCore Linux from the Applications menu. Back up the destination disk first; partitioning can erase existing data.
